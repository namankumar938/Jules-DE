# Retail Data Analytics Pipeline

This project implements a data analytics pipeline for a retail platform. It captures and analyzes customer purchase behavior across different product categories and payment methods. The pipeline processes purchase data (simulated in this version), cleans and transforms it, and generates meaningful KPIs.

## Project Structure

```
.
├── .gitignore          # Specifies intentionally untracked files that Git should ignore
├── data/               # Directory for data files
│   ├── sample_purchases.csv      # Raw sample data generated by the script
│   ├── processed_purchases.csv   # Processed and transformed data
│   └── kpis.json                 # Calculated KPIs in JSON format
├── notebooks/          # Jupyter notebooks for reporting and visualization
│   └── reporting_notebook.ipynb  # Notebook to visualize KPIs
├── scripts/            # Python scripts for the pipeline
│   ├── generate_sample_data.py # Generates raw sample purchase data
│   └── process_data.py         # Ingests, cleans, transforms, and calculates KPIs
├── tests/              # Unit tests for the project
│   └── test_process_data.py    # Tests for data processing and KPI calculation logic
└── venv/               # Python virtual environment (ignored by Git)
```

## Setup and Installation

1.  **Clone the repository (if applicable):**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **Create and activate a Python virtual environment:**
    It's recommended to use a virtual environment to manage dependencies. The scripts are set up to re-create a `venv` directory and install packages if run via the `run_in_bash_session` tool in some environments, but for local development:
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3.  **Install dependencies:**
    The necessary Python packages are pandas, Faker (for data generation), matplotlib, seaborn, and ipykernel (for the notebook).
    ```bash
    pip install pandas faker matplotlib seaborn ipykernel
    ```

## Running the Pipeline

The pipeline consists of two main scripts:

1.  **Generate Sample Data:**
    This script creates `data/sample_purchases.csv`.
    ```bash
    # Ensure your virtual environment is active
    python scripts/generate_sample_data.py
    ```
    Alternatively, if using the tool environment where venv might not persist:
    ```bash
    # rm -rf venv # Optional: start fresh
    # python3 -m venv venv
    # venv/bin/pip install pandas faker
    venv/bin/python scripts/generate_sample_data.py
    ```


2.  **Process Data and Calculate KPIs:**
    This script takes the raw sample data, processes it, and generates `data/processed_purchases.csv` and `data/kpis.json`.
    ```bash
    # Ensure your virtual environment is active
    python scripts/process_data.py
    ```
    Alternatively, if using the tool environment:
    ```bash
    # rm -rf venv # Optional: start fresh
    # python3 -m venv venv
    # venv/bin/pip install pandas faker
    venv/bin/python scripts/process_data.py
    ```

## Viewing Reports

A Jupyter notebook is provided to visualize the generated KPIs.

1.  **Ensure you have Jupyter Notebook or JupyterLab installed:**
    If not already installed (ipykernel was installed above, but you might need the frontend):
    ```bash
    pip install notebook  # For classic Notebook
    # or
    pip install jupyterlab # For JupyterLab
    ```

2.  **Run Jupyter:**
    Navigate to the project root directory in your terminal (where `notebooks/` directory is).
    ```bash
    # Ensure your virtual environment is active
    jupyter notebook
    # or
    jupyter lab
    ```
    This will open a new tab in your web browser. Navigate to `notebooks/reporting_notebook.ipynb` and open it. Run the cells to see the visualizations.

## Running Tests

Unit tests are provided to verify the correctness of the data processing logic.

1.  **Run tests from the project root directory:**
    ```bash
    # Ensure your virtual environment is active
    python -m unittest tests/test_process_data.py
    ```
    Alternatively, if using the tool environment:
    ```bash
    # rm -rf venv # Optional: start fresh
    # python3 -m venv venv
    # venv/bin/pip install pandas
    venv/bin/python -m unittest tests/test_process_data.py
    ```

## Key Functionality

*   **Data Ingestion:** Loads data from a CSV file.
*   **Data Cleaning:** Handles missing values (currently minimal due to clean generated data) and converts data types (e.g., `timestamp`).
*   **Data Transformation:** Calculates `total_purchase_amount` per transaction.
*   **KPI Calculation:**
    *   Total revenue.
    *   Total revenue by product category.
    *   Top N selling products.
    *   Preferred payment methods.
*   **Data Storage:** Saves processed data to CSV and KPIs to a JSON file.
*   **Reporting:** Visualizes KPIs in a Jupyter Notebook.
*   **Testing:** Includes unit tests for core logic.
